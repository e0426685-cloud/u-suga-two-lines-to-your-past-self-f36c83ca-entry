Two lines to my past self: don't delete Grandma's last voicemail — hearing her laugh again taught me to call the people I love before it's too late.

## How it works

`main.py` (Python 3.13 standard library only) writes exactly two lines to
`/output/entry.txt`: line one warns the past self about one specific,
concrete moment — a voicemail on 3 October — and line two traces the cause
and effect, what that saved message changed. The output is deterministic,
1–280 characters, valid UTF-8, and written with mode 0644 so the grader
can read it.

## Run it

```sh
python3 main.py
```
